## 0. 摘要

1. 【决策】交付形态：每种语言一份 JSONC，键路径与文档 06 §4.2 一致，去掉 `//` 注释即可作为 `src/locales/<code>.json`。注释写明该字段承载的关键词（K1–K10，文档 03 §2）。三份首页 JSON 及 about、扩展页文案都已用脚本跑过文档 06 §3.7 的相关规则和本版新增的裁定检查（键一致、长度、`[[ ]]` 与 `{wbr}` 位置、占位符、ref 白名单、禁用词、替换性措辞、样张约束），0 error（§9）。原型 `prototype/tools/render.mjs` 从 §2、§3 解析成功（§9 V2）。
2. 【裁定】定位（R39）：WordByWord 是"**用真实网页学外语的阅读助手**"。en 定义句为 "WordByWord is a reading assistant for language learners on iPhone and iPad."，ja / zh-Hans 写"为外语学习者设计 / 外国語を学びながらWebを読む人のための"。定义句出现在 `hero.lede`、FAQ `what-is`、`/about/` lede 和事实表；eyebrow、`featuresIntro.lede`、页脚 tagline 同步写明受众。WBW 不以"学英语"作主词，通用的"语言学习"属于 WBW。
3. 【裁定】首页关键词改为产品 / 品类意图（R46、SEO-01）：en title "WordByWord: Bilingual Web Page Translator App for iPhone"，zh-Hans "网页双语对照翻译 App"，ja 保留"…アプリ"。H1 写"段落 + 译文在下方"，不暗示整页；H1、`cta.title` 都不与 G1 指南的 how-to 标题重复。title / description / H1 与文档 03 v1.1 §3.9 草案对齐。
4. 【决策】功能区共 10 个 id（`swipe lookup x chunks speech syntax engines display history devices`），按文档 05 §4.3 的 L1 / L2 / M / S 槽位渲染（§1.6），功能块为 H3（R13）。功能名第一次出现时用 App 内的本地化叫法（从 xcstrings 抽取），正文用用户的搜索说法（文档 03 §1.2 规则 3）。荧光笔 `[[ ]]` 只用于 hero H1 的一个短语（≤3 个拉丁词或 ≤6 个 CJK 字）和 OG 标题，功能 H3、语言段 H2 一律不加（R65、VIS-02）。
5. 【决策】FAQ 13 问：在 v1.0 的 10 问之外，按 R73 新增 `account`（是否要注册）、`restore`（恢复购买）、`android`（有无安卓版）；删除"名字含义 = 逐词细读"的叙事（R73、PRO-18）。`english-learner` 仍排倒数第二（文档 04 §3.2），`devices` 最后，并分 S0 / S1 两种答案（R45）。不输出 FAQPage（R5）。
6. 【裁定】SE 推荐（R40–R44）：叙事从"WBW 管多语言、SE 可能更适合你"改为"**互补、也值得一试**"；SE 区块 H2 以 SurfEnglish 开头；卖点只写分级英语新闻、复习游戏、从 Safari 分享文章（R41），不写端侧 / 离线语音；SE 卡片用文字链接，不用黑色徽章（R43）；配图改为 SE 游戏页（R44）。落点 ③ 语言段提示**删除**（R42，取代 R4），`sibling.languagesTip` 键已删除。zh-Hans 页只渲染 ② FAQ、④ 页脚、⑤ about，FAQ 注明 SE 未在中国大陆上架（R42）。
7. 【事实修正】译文样式是 **7 种**（引用、背景色、边框、实线 / 虚线 / 波浪下划线、无样式），见 `TranslationSettings.swift:460-476`。全站文案不写样式数量（R26）。

### 1.2 关键词注释与 JSONC 约定

- 注释写在被注释键的上一行，格式为 `// KW K1 主「…」+ 次「…」（出处）`。K 编号同文档 03 §2.1：K1 网页双语阅读 / 右滑翻译，K2 语境查词，K3 朗读，K4 句法，K5 Chunks / Action Flow（不争主词），K6 历史，K7 引擎，K8 语言，K9 X，K10 免费与 Plus。没有注释的键不承担关键词任务。
- K1 主词按 R46 改为产品 / 品类意图（en "bilingual web page translator app for iPhone"，zh-Hans "网页双语对照翻译 App"，ja / ko 保留含アプリ / 앱 的写法）；"how to translate web pages on iPhone (keep the original)" 一类 how-to 查询只归 G1 指南，首页 title / H1 / `cta.title` 不得与 G1 标题重复。通用的"语言学习 / learn languages by reading"属于 WBW（R39），可进 description、eyebrow 和 K1 次词。
- `seo.*` 只供构建 lint 和写作参考（文档 03 §3.8），不输出 `<meta name="keywords">`（R6）。
- 转成 JSON 的方法（Node 24，零依赖，能正确跳过字符串里的 `//`）：

```js
// scripts/jsonc-to-json.mjs  用法：node scripts/jsonc-to-json.mjs docs/…/en.jsonc > src/locales/en.json
import { readFileSync } from 'node:fs';
const t = readFileSync(process.argv[2], 'utf8'); let o = '', s = false;
for (let i = 0; i < t.length; i++) {
  const c = t[i];
  if (s) { o += c; if (c === '\\') o += t[++i]; else if (c === '"') s = false; continue; }
  if (c === '"') { s = true; o += c; continue; }
  if (c === '/' && t[i + 1] === '/') { while (i < t.length && t[i] !== '\n') i++; o += '\n'; continue; }
  o += c;
}
process.stdout.write(JSON.stringify(JSON.parse(o), null, 2) + '\n');
```

**断行记号 `{wbr}`（R61、I18-03）**：只用于 ja，只能出现在标题类字段：`hero.title`、`featuresIntro.title`、`features[].title`、`gallery.title`、`languages.title`、`pricing.title`、`sibling.card.title`、`faq.title`、`cta.title`。构建时在可见文本里转成 `<wbr>`，在 `<title>`、meta、OG、JSON-LD、alt、aria-label 中剥除；它不是数据占位符，`fill()` 必须原样放行。不再用 `｜` 作断行标记（`｜` 是 CJK title 的分隔符）。每段 ≤10 字的段长校验只对 ja 生效。

**复数写法（R62、I18-02）**：数字占位符后面接可数名词时，ru、uk、pl、ar（以及 CLDR 有 few / many 类别的其他语言）必须写成复数对象，最小实现为 ICU 风格：

```text
{targetLanguages, plural, one{# язык} few{# языка} many{# языков} other{# языка}}
```

`#` 代入数值；分支名用 CLDR 类别（zero / one / two / few / many / other），`other` 必填；构建时用 `new Intl.PluralRules(code).select(n)` 选分支（文档 06 实现）。当前值下的结果：ru / uk 的 21 属于 one（"21 язык / 21 мова"），20 属于 many；ar 的 5、10 属于 few，20–50 属于 many，100–500 属于 other。en、ja、zh-Hans、zh-Hant、ko、vi、th、id 不需要复数对象。en 中含"数字 + 名词"的键（译者需要特别处理）：`languages.title`、`languages.uiCount`、`languages.targetCount`、`gallery.items[languageList].caption`、`pricing.table.perDay`、`faq.items[free].a`、`faq.items[languages].a`、`cta.recap`、`sibling.card.note`、`chromeExtension.languages.text`、`chromeExtension.faq[languages].a`、`chromeExtension.faq[iphone].a`。

### 7.1 工作方式与交付

1. **输入**：`en.json`（§2 去掉注释后的结果）；本简报；文档 03 v1.1 §2.2 / §2.3（各 locale 主关键词，R46 之后 K1 为产品 / 品类意图）和 §3.9（title、description、H1 草案）；文档 04 §5（SE 推荐的规则与按语言资料，**措辞以本文为唯一来源**，R75；叙事以本文 §2 的 R40 写法为准）；`src/data/glossary/<locale>.json`（§7.2 生成，R64）；`src/locales/_legacy/` 翻译记忆（文档 06 §4.5，**只当术语参考，内容不保证正确**，F11）。zh-Hant 另以 §4 的 zh-Hans 定稿作为结构参考，**禁止直接做繁简转换**（I18-07），用词按 §7.2.4。

### 7.4 语气

- 用陈述句，主语是用户的动作，后面接结果（"向右滑动段落 → 译文插在下方"），短句为主。不用感叹号、emoji，不用最高级（best、#1、only、唯一、最强、革命性），不用"智能助手 / Smart Assistant / スマートアシスタント / 스마트 도우미"之类泛词作 title 主词（文档 03 §3.1）。R39 的定义句 "a reading assistant for language learners" 只在定义句里使用（D13）。
